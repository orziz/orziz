### [Odai](https://github.com/orziz/odai)

A general-purpose task-governance framework for AI agents. Odai helps an agent align goals with facts, act within authorization and risk boundaries, and keep going until the result is actually verified and deliverable.

It is not limited to coding: the same governance applies to research, writing, data work, browser tasks, and project execution. Odai is available as a portable **Skill**, a selectable **DeepSeek Harness Agent**, and a profile-wide **DeepSeek Harness Plugin**.
